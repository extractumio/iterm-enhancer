# v0.22.0 — iterm-enhancer: a new name, a phone-first web terminal

## What changes

- **New name: iterm-enhancer.** The project, its command (`iterm-enhancer`), its folder
  (`~/.iterm-enhancer/` on the Mac and on remote hosts) and its repository
  (`extractumio/iterm-enhancer`) have a new name. This is a new setup: an install of the
  earlier name is not upgraded or moved (see Upgrading).
- **Phone controls.** On a touch screen the hot keys panel is hidden until you ask for it: two
  floating buttons at the bottom right open the keyboard and the hot keys. New hot keys: ⇧Tab,
  ⇧← and ⇧↩.
- **Shift+Enter is its own key.** Shift+Enter and Ctrl+Enter reach the program as their own
  keys (as iTerm2 reports them to programs that ask), so Claude Code, Codex and editors start a
  new line instead of sending.
- **Wide screens.** At 1400 px and wider, Files is docked on the right like the session list,
  with × to close it, and a file opens in a window over the terminal. Docked Files follows a
  `cd`.
- **Remembered views.** Session groups collapse, and Wrap, Grid or Fit is remembered for each
  session; the one chosen last applies to sessions the browser has not seen.
- **Fixed:** Files and the file viewer in the browser wore the colors of the pane focused on
  the Mac instead of the shown one; docked Files could stay empty on first load.
- **Install:** the PATH tip is cornflower blue (the gray one was hard to read).

## Upgrading

An install of the earlier name does not upgrade to this release. Remove it first, then
install this one:

```sh
~/.iterm-filebrowser/bin/iterm-filebrowser uninstall
curl -fsSL https://github.com/extractumio/iterm-enhancer/releases/latest/download/install.sh | sh
```

The new install starts with a fresh state: switch web access on again with
`iterm-enhancer web on`, and enable remote hosts again from the Files panel. The old
`~/.iterm-filebrowser` folder (token, workspaces, logs) is left for you to delete.

## Validation

Rust, Python and UI unit tests (including the new key encoding tests), the private browser
checks (204) and the security check pass. The web app ran in WebKit and Chromium at phone,
tablet, desktop and wide sizes against a mocked server: the floating buttons, hot keys,
Shift+Enter, the docked Files and floating viewer across 1400 px, collapsed groups, modes
applied on reload, and the shown pane's colors in the embedded Files panel.
