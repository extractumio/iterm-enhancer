# v0.31.0 — Search the session's whole history

## What changes

- **Search.** In the web app, the magnifier at the terminal's top right opens a field with
  **Find**. It looks through the session's whole history, older lines and folded parts too, not
  only what the page has loaded; case does not matter, and lines iTerm wrapped count as one.
  It says how many it found ("1 / 17"), shows the first, and ↓ or Enter go to the next, ↑ or
  Shift+Enter to the one before. The match shown is marked white, also inside a rendered
  Markdown or code widget, and every match is a short white mark on the terminal's right edge;
  press one to go there. The magnifier again, ×, Esc or another session closes it.
- **The phone's floating buttons** (keyboard, hot keys) and the magnifier have the same nearly
  round, slowly drifting shape as the bookmark buttons.
- **The bookmarks' button** shows only in a session that has bookmarks, with their number on it.
- **The bookmark bar** has no orange edge any more, and a bookmark's wavy line stands a little
  closer to its text.

## Upgrading

Run `~/.iterm-enhancer/bin/iterm-enhancer upgrade`. Open web app pages reload themselves, and
you stay signed in.

## Validation

Rust, Python and UI unit tests pass, with new tests of the search on the Mac (by row, case
aside, across a wrap, two on a row, the count past 2,000 matches, a cell a program skipped as a
space, one 11,000-row line in 3 ms). The browser checks pass in Chromium and WebKit, among them
new ones for the magnifier and its field, the first match in older lines, next and the one
before, the second match on a row, a match across a long wrapped row, a history numbered anew,
"Not found", closing, and the bookmarks' button only with bookmarks.
