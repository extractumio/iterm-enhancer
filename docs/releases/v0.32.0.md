# v0.32.0 — Editing a coding agent's input from the browser

## What changes

- **A held delete goes by words.** Hold delete in a coding agent's input box or at a shell's
  prompt: it deletes a character at a time, and after 1.5 s (about 2 s on a phone) a word at a
  time, so a long text goes quickly. Quick taps stay single characters, and other programs
  (nano, an editor, a shell over ssh) still get one character at a time.
- **A click moves the cursor.** With a mouse, a click on a coding agent's input or a shell's
  prompt moves the cursor there, as a tap does on a phone; ⌘-click still opens links.
- **Lines no longer jump in a coding agent's input.** In Wrap, a space typed at the end of a
  full row showed the cursor on a new line, which went back up with the next word; and a line
  you ended with Shift+Enter after a long row could be glued to the next one. The page now
  re-joins the input's rows exactly as Claude Code wraps them.
- **New tabs open in the background.** [+] no longer brings iTerm2's window to the front or
  back from the Dock: keep iTerm2 minimized and work from the browser. "New window" shows the
  new window without taking the focus, and leaves the minimized ones down (iTerm2 3.7).
- **Markdown a tool printed is one widget from its first line.** A document a coding agent's
  tool printed (with `sed -n`, say) began a few lines down, leaving its title and first lines
  as text; it now starts on the tool's first line.

## Upgrading

Run `~/.iterm-enhancer/bin/iterm-enhancer upgrade`. Open web app pages reload themselves, and
you stay signed in.

## Validation

Rust, Python and UI unit tests pass, with new tests of the held delete (a keyboard's repeats,
a phone's, panes that take no words), Claude Code's wrap of its input (measured in iTerm2: rows
of the width less 2, the cursor alone after a space at a full row's end), a document that starts
on a tool's first line, and the background request for a new tab. The browser checks pass,
among them new ones for the cursor after a space at a full row's end, a line ended after a long
row, a click that moves the cursor up a row and along it, ⌘-click moving nothing, and a held
delete turning to words, a drag and a double click still selecting, and a shell's words off
after Enter. In iTerm2, [+] leaves the window's selected tab as it was. Claude Code's wrap was
measured in a window of its own, with nothing submitted.
