# v0.30.0 — Typing on a phone, and bookmarks at hand

## What changes

- **A held delete repeats on a phone.** Holding delete on the iPhone's keyboard now deletes
  until you let go, as in any text field (each delete is one backspace to the pane).
- **Paste and moving the cursor in a coding agent's input box.** A long press anywhere in the
  box offers iOS's Paste. A finger that rests a moment and then slides left or right moves the
  cursor along the line, a character a step. A swipe up or down that starts in the box still
  scrolls.
- **This session's bookmarks from one button.** A round orange button at the terminal's top
  right, with the number of bookmarks on it, opens the list of this session's bookmarks; a
  second press closes it.
- **A bookmark keeps its text's look.** The text brought into view is marked by a soft wavy
  line on its left instead of an orange background.
- **Long paths are whole again.** A path longer than a terminal row, which a coding agent
  broke at the row's edge, gets its image button, one underline and a working click, and
  copies without a space in it.
- **A click on a line with an image button or a widget opens its link.** Clicks on such a
  line's own text were stopped before they reached the terminal.
- **The header names what runs first:** program and folder, then the profile and the tab, then
  the titles.
- **A session with bookmarks** keeps its row's layout in the session list on a phone (its
  title was pushed out).

## Upgrading

Run `~/.iterm-enhancer/bin/iterm-enhancer upgrade`. Open web app pages reload themselves, and
you stay signed in.

## Validation

Rust, Python and UI unit tests pass, with new tests of when rows a program broke inside a word
join without a space (and when two paths stay apart). The browser checks pass in Chromium and
WebKit, among them new ones for a long broken path (its image button, underline, a click on its
second half, copying), the bookmarks button and its list, the wavy line, and, at a phone's
size with touch, the kept character for a held delete, the input box under the keyboard field,
sliding to move the cursor and swiping to scroll. iOS's own key repeat and menus are not
automated: try a held delete, a long press and a slide on an iPhone.
