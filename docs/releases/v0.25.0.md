# v0.25.0 — The web app: selection on iOS 26.4+, remembered sign-ins, reminders

## What changes

- **Long press works again on iOS 26.4 and later.** Safari selected the text but showed no
  highlight, handles or Copy menu. Each paragraph of the terminal is now a block of its own,
  which iOS shows a selection in; wrapped prose is still joined, also where it runs from the
  history into the screen.
- **Signed in across restarts.** An upgrade or a restart of iTerm2 no longer asks for the
  password again. The bridge keeps only a hash of each sign-in, bound to the password: a new
  password, signing out or `iterm-enhancer web off` signs every browser out.
- **Reminders of questions elsewhere.** When a coding agent in another session waits for your
  answer, a reminder stands over the terminal (at the side on a computer, under the tabs on a
  phone) until you close it, open that session from it, or the question is answered. The
  waiting badge in the list is brighter and blinks.
- **A clearer session list.** A bar in the profile's color replaces the dot, full for the session
  you see and breathing while its agent works. The second line names the program first, then
  the folder, then titles; a stale title such as "ssh" on a pane now running claude is gone.
- **Merge windows.** Moves every tab into one iTerm2 window, and each tmux session's tabs into
  one window of their own, without bringing iTerm2 to the front. It asks first: iTerm2 cannot
  undo it.
- **[+] where you are.** A new session opens right after the selected one, in its folder; in
  tmux, as a new tmux window there.
- **Links you can see.** Web addresses and file paths have a faint dotted underline. With a
  mouse they open on ⌘-click (Ctrl-click off a Mac); on a phone, on a tap.
- **View instead of File.** Closing its last file goes back to the terminal, and on a phone a
  Terminal button sits at the bottom of View.
- **Drop files** on the page to upload them; their paths are typed into the pane, as Upload
  does.
- **Smaller things.** Long separator lines span the whole view. On a computer the terminal has
  the keys when a chat opens and after renaming. On a phone a tap right of the cursor no longer
  takes Claude Code's faint suggestion.

## Upgrading

Run `~/.iterm-enhancer/bin/iterm-enhancer upgrade`. Open web app pages reload themselves; sign
in once more after this upgrade, then sign-ins outlive restarts.

## Validation

Rust, Python and UI unit tests, the private browser checks (including new checks of the whole
web app against a fake bridge: reminders, underlines, View, file drops, focus), and the
isolated iTerm2 checks pass. The iOS selection was bisected and confirmed on an iPhone with
iOS 26.6.1, where a remembered sign-in also survived a restart; the rest was checked in WebKit,
Chromium and the iOS 26.3 Simulator.
