# v0.21.0 — Web access: your iTerm2 sessions and files in a browser

## What changes

- **Web access (new, off by default).** The bridge can serve your iTerm2 sessions to a
  browser on another device: an iPhone, an iPad or another computer, on the local network or
  over Tailscale. Switch it on with `iterm-filebrowser web on` (it asks for a password the first
  time) or with the new globe button in the Files header; `iterm-filebrowser web` shows its
  addresses and any error, `web off` and `web password` do what they say.
- **Sessions, as in iTerm2.** Every window, tab and pane, named by the title you gave it (else
  the program's), with a blue laptop for this Mac and a violet server for a remote host.
- **A terminal you can work in.** The pane in its profile's colors and font, typing, a hot keys
  panel (keyboard, Copy, Paste, Tab, ^C, Esc, Ctrl, Alt, arrows, Home/End, PgUp/PgDn),
  scrollback, selection that stays while output continues. On a phone lines re-flow to the
  screen; **Grid** keeps iTerm2's layout, **Fit** scales it to the width, and **Resize iTerm to
  this screen** changes the window on the Mac until you restore it. Typing selects the pane's
  tab in iTerm2, because iTerm2 refreshes hidden tabs only a few times a second.
- **Files in the browser.** The Files panel for the shown pane's folder, remote hosts with a
  helper included, and its viewer and editor; web links open in your browser. Actions that
  act on the Mac itself (Finder, apps, typing into a terminal) are not offered there.
- **Security.** The password is kept only as a salted hash; sign-in is an HttpOnly cookie
  (7 days, 30 over HTTPS); wrong passwords are checked one at a time and make an address, then
  everyone, wait; only this Mac's names and addresses are served; the browser never holds the
  File Browser's token, and only file work reaches it. Plain HTTP is for networks you trust:
  for anything else use HTTPS with `tailscale serve --bg 8765`.
- **README** is shorter and starts with the key features.

## Upgrading

Run `~/.iterm-filebrowser/bin/iterm-filebrowser upgrade`. Open panels reload by themselves;
web access stays off until you switch it on. If another device gets no answer while the page
opens on the Mac, allow incoming connections for iTerm2's Python in the macOS Firewall
(System Settings → Network → Firewall → Options); over Tailscale, check that its access rules
let the device reach the Mac.

## Validation

Rust, Python and UI unit tests, the private browser checks (204) and the isolated iTerm2
checks pass; the web server's sign-in brake, request limits, proxy rules and page are tested
without iTerm2. The web app ran against the installed build on this Mac (local and remote
files, editing, the panel's globe menu), in WebKit and Chromium at phone, tablet and desktop
sizes, and on an iPhone over Tailscale with HTTPS.
