# v0.33.0 — Moving in a coding agent's input by the lines you see

## What changes

- **↑ and ↓ move by the page's lines.** The web app re-flows Claude Code's input to the
  browser's width, but ↑ and ↓ moved by iTerm2's rows at iTerm2's column, far from the
  character drawn above the cursor. They now go to the character the page draws above or
  below, keep their column across short and blank lines, and a held ↑ stops at the start
  instead of running into history. On the input's first row ↑ still recalls Claude Code's
  history, and an "@" or "/" list keeps its own ↑ and ↓.
- **A click or a tap anywhere in the input moves the cursor there**, across lines too, never
  past the text typed.
- **Claude Code's questions keep their arrow keys.** In a question menu, ↓ on the second item
  opened the next question instead of the third item: the menu is drawn between two rules,
  like the input, and the page took it for the input. The input is now told by its prompt, so
  ↑ and ↓ in a menu go to Claude Code as they are, and a phone no longer draws the menu as
  the input panel.

## Upgrading

Run `~/.iterm-enhancer/bin/iterm-enhancer upgrade`. Open web app pages reload themselves, and
you stay signed in.

## Validation

Rust, Python and UI unit tests pass, with new tests of Claude Code's stepping over its input (a
character at a time, one more at a wrap at a space or a line end, none inside a word broken at
the edge, an emoji as one) and of telling the input from a menu (a tab bar, a question, a
menu's chosen item right below the rule, a permission). The browser checks pass in Chromium
and WebKit against a fake Claude Code playing the rules measured in iTerm2: ↑ lands on the
character drawn above, ↓ comes back, only ← and → are sent, quick presses with a slow echo,
history on the first row, a held ↑, blank lines, a line out of sight, an "@" list, clicks, and
Claude Code's own rows recorded while typing; in its question menu ↓ goes as one ↓. Claude
Code's stepping was measured in iTerm2 in windows of its own, with nothing submitted.
