# v0.26.0 — The web app: a tidy agent pane on a phone

## What changes

- **The agent's input as a panel.** In a Claude Code or Codex pane on a phone, the input box is
  drawn as a rounded panel at least two rows high, without the agent's rules and the title on
  its top rule. It stays in sight while you type, with the keyboard up or closed.
- **The footer behind a button.** The status lines under the input (folder, model, context,
  limits, permission mode) wait behind an ⓘ button beside the keyboard button; the page
  remembers your choice. A "/" or "@" list, or a new notice there, still shows.
- **More room for the output.** In an agent's pane on a phone, whole-line key hints such as
  "(ctrl+b to run in background)" are left out, and a notice pushed to the right edge loses
  the spaces that would wrap it.
- **No empty view.** After a clear, and in a new terminal, the prompt stands at the top of
  iTerm's screen; the page showed only the empty rows below it. Those rows are now left out,
  so the prompt is in sight on every device.

Computers with a mouse and the Grid mode show the screen as before, apart from the empty rows.

## Upgrading

Run `~/.iterm-enhancer/bin/iterm-enhancer upgrade`. Open web app pages reload themselves, and
you stay signed in.

## Validation

Rust, Python and UI unit tests and the private browser checks pass, including new checks of
the panel, the footer button, a "/" list, the panel's height, and a prompt over empty rows,
also when it arrives after an empty screen. Live Claude Code and Codex sessions and a new
iTerm2 window were rendered from their screens in WebKit at phone width and in the iOS 26.3
Simulator; the build was checked on an iPhone.
